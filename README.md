# Dev Dynasty Agency Website

## Project Overview

This is a modern and responsive agency website developed for Dev Dynasty Agency. The website showcases services, projects, team information, and contact details in a professional layout.

## Features

* Responsive Design
* Modern User Interface
* Dark/Light Mode
* Smooth Scrolling Navigation
* Contact Form
* Mobile-Friendly Layout
* Fast Loading Performance

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

├── index.html
├── style.css
├── script.js
└── assets/

## Installation

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
